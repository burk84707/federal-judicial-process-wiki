# DOJ publication of PATTERN on July 19, 2019

## Proposition supported

DOJ publicly released the initial risk-and-needs assessment system, PATTERN, on July 19, 2019 and identified the publication as satisfying the First Step Act's statutory deadline.

## Material limitation

This record establishes publication and implementation history, not the validity of an individual PATTERN score or the later time-credit regulation.
